Соединение
──────────
  транспорт:   stdio, сервер запущен дочерним процессом
  команда:     go run ./cmd/animals-mcp

Сервер
──────
  имя:         animals-reference 1.0.0
  название:    Справочник по животным
  протокол:    2026-07-28
  умеет:       tools (сообщает об изменениях списка)
  инструкция:  Сервер отвечает на вопросы о животных. Инструменты с префиксом
               list_/get_/search_/compare_/random_ работают по локальному
               справочнику и доступны всегда; wikipedia- и taxon-инструменты
               ходят в русскую Википедию и в таксономическую базу GBIF и требуют
               сети.

Инструменты (11)
────────────────

 1. compare_animals — Сравнение животных
    Сравнение двух-четырёх животных справочника по выбранным полям. Возвращает
    таблицу: строка на поле, колонка на животное, с пометкой совпадающих
    значений.
    аргументы:
      * animals  array[string] от двух до четырёх животных: идентификаторы или
                               названия
        fields   array[string] какие поля сравнивать; по умолчанию все
      * — обязательный аргумент

 2. get_animal — Карточка животного
    Полная карточка животного из локального справочника по идентификатору,
    русскому или латинскому названию. Если записи нет, возвращает found=false и
    похожие записи, а не ошибку.
    аргументы:
      * animal  string идентификатор, русское или латинское название животного
      * — обязательный аргумент

 3. list_animals — Список животных
    Список животных локального справочника с необязательными фильтрами по классу
    и среде обитания. Возвращает краткие записи; подробности даёт get_animal.
    аргументы:
        class    string  класс животного; допустимые значения возвращает
                         server_info
        habitat  string  среда обитания или регион, поиск по вхождению: «лес»
                         найдёт «смешанный лес»
        limit    integer сколько записей вернуть, 1..100; по умолчанию 20
        offset   integer сколько записей пропустить; по умолчанию 0
      * — обязательный аргумент

 4. match_taxon — Сверка латинского названия
    Сверка латинского (научного) названия с таксономической базой GBIF.
    Возвращает found, ранг, статус, уверенность и положение в системе. Нечёткое
    совпадение найденным не считается: похожее название не означает то же
    животное.
    аргументы:
      * scientific_name  string латинское (научное) название, например Lynx lynx
      * — обязательный аргумент

 5. random_animal — Случайное животное
    Случайная карточка из локального справочника. Аргументов нет.
    аргументов нет

 6. read_wikipedia — Чтение статьи Википедии
    Чтение статьи русской Википедии по точному заголовку. Без section возвращает
    вступление и оглавление, с section — текст этого раздела. Так статья
    читается по частям, а не целиком. Перенаправления раскрываются, итоговый
    заголовок в поле title.
    аргументы:
      * title    string точный заголовок статьи, как в результатах
                        search_wikipedia
        section  string название раздела, например «Питание»; без него вернётся
                        вступление и оглавление
      * — обязательный аргумент

 7. search_animals — Поиск по справочнику
    Поиск по локальному справочнику: свободный запрос, тип питания, среда
    обитания и границы веса. Условия складываются. Вес сравнивается по
    пересечению диапазонов: животное весом 18–30 кг подходит и под
    min_weight_kg=25, и под max_weight_kg=20.
    аргументы:
        diet           string тип питания, например «хищник» или «травоядное»
        habitat        string среда обитания или регион
        max_weight_kg  number верхняя граница веса в килограммах
        min_weight_kg  number нижняя граница веса в килограммах
        query          string свободный запрос: слово ищется в названиях,
                              описании, пище и регионах
      * — обязательный аргумент

 8. search_wikipedia — Поиск в Википедии
    Поиск статей в русской Википедии по названию животного. Возвращает заголовки
    с фрагментами. Наличие результатов не означает, что статья о запрошенном
    животном есть: сверяйте заголовок с запросом.
    аргументы:
      * query  string  название животного на русском
        limit  integer сколько результатов вернуть, 1..5; по умолчанию 5
      * — обязательный аргумент

 9. server_info — Сведения о сервере
    Версия сервера, список его инструментов, сводка по локальному справочнику,
    подключённые источники и счётчик вызовов за текущую сессию. Аргументов нет.
    аргументов нет

10. taxon_tree — Дерево классификации
    Дерево классификации таксона из GBIF от царства до самого таксона. Принимает
    usage_key из match_taxon или латинское название — тогда сверка делается
    сама.
    аргументы:
        scientific_name  string  латинское название вместо ключа; сервер сверит
                                 его сам
        usage_key        integer ключ таксона в GBIF из результата match_taxon
      * — обязательный аргумент

11. vernacular_names — Народные названия
    Народные (обиходные) названия таксона на заданном языке по данным GBIF. По
    умолчанию русский (rus). Позволяет проверить, что русское название
    действительно относится к этому таксону.
    аргументы:
      * usage_key  integer ключ таксона в GBIF
        language   string  код языка ISO 639-3; по умолчанию rus
      * — обязательный аргумент
